# x-ask — 把模糊输入问成可判定的需求

## 核心原则

**问的目的是能判定，不是聊明白。**

问完之后还写不出"怎么算做完"，等于没问。

## 何时不用

- 你能直接写出验收标准 → 不用问，去写。
- 你要的是事实（现在有没有限流、谁在调这个接口）→ 那是查，不是问。
- 改动不改行为、不改契约（拼写、格式、单行修复）→ 直接做，贴证据。

## 先查再问

**每个问题先问自己：这个答案在仓库里能找到吗？**

能找到就去查，查完再问剩下的。把对方已经写下的东西再问一遍，是这类工具最常见的失败方式。

判据：一个问题如果搜一下就能答，它就不该出现在问题列表里。

## 怎么问

一轮最多 5 个问题，每个问题必须带一个推荐答案。

```
Q1 <问题>
→ 我的推荐：<答案>。理由：<一句>
```

推荐不是替对方决定，是**把分歧暴露出来**——对方说"不对"的那一刻，真正的约束才出现。

只抛问题不给推荐，是把判断责任推回去。那不是中立，是回避。

## 先对一次前提

查完之后、问四问之前，先看一件事：**你要做的事，和证据指向的问题，是不是同一个？**

- **不做会怎样？** 要具体现象或数字，不要"会出事"。
- **仓库里的证据支持这个做法吗？** 慢查询日志、报错、监控、最近的改动。

| 证据 | 怎么做 |
|---|---|
| 支持 | 记下代价，进四问 |
| **指向别的原因** | **在四问之前先说出来**：摆证据，给出你建议的替代动作，再问"仍要按原计划做吗" |
| 不够判断 | 写 `未验证：<缺哪份证据>`，进四问 |

判据：如果"这可能不是对的解法"排在四个问题后面，或者只写成一句"如果……"的条件句，等于没说——用户会照着原计划做下去。

替代动作要具体（加哪个索引、错开哪个任务、改哪条查询），不是"建议排查一下"。

## 四个必答

这四个都有答案就停。

| # | 问 | 什么算答上了 |
|---|---|---|
| 1 | 你到底想要什么？ | 一句话，且**有可作用的对象**——说"加超时"要能说出加在哪个调用上 |
| 2 | 怎么算做完了？ | 能被判真假。软件里通常写成 Given-When-Then；其他场景写成可观察到的结果 |
| 3 | 这次**不**做什么？ | 至少一条。一条都写不出来，说明范围没想过 |
| 4 | 多大？ | 单点 / 单模块 / 跨模块 / 不可逆 |

第 4 问只问，不判。判规模是别人拿到这四个答案之后做的决定。

## 答不上来怎么办

不许替对方补全。写 `未验证：<缺什么>`，并说明缺它会卡住什么。

四问里哪一条没答上，就直接写 `未验证：<哪一问>`，不要写成"没有回答""待定""见 Q5"。

- `未验证：超限时的返回码` → 会让"怎么算做完"无法判定
- `未验证：现有峰值 QPS` → 会让阈值定不了，但不阻塞继续

## 什么时候停

四问齐了，或者每条答不上的都标了 `未验证：` —— 停。

四问齐了之后，**只剩两类可以再问一轮**（≤5 个，带推荐）：

- 答案与仓库现状冲突（配置里已经是 50，你要 101，以哪个为准）
- 验收标准缺可判定的依据（"第 101 次"按什么维度数、用户 id 从哪来）

架构选型、日志落点、测试框架、窗口算法，不在这里问——那是下游设计的活。问完这一轮必须落输出。

不追求"完全理解"。理解是无底洞，能判定才是终点。

## 输出

四问的答案 + `未验证` 清单。

证据按 `x-quality` 的证据格式写：`命令 → 输出`、`文件:行 → 原文`、`未验证：<缺什么>`。三种之外的写法不算证据。

## 禁止

- 问能查到的（先查再问）
- 给问题不给推荐（那是回避）
- 替对方补全答案（那是编造）
- 一轮超过 5 个问题（问不完说明没排序）
- 问完不落输出（问了不落，等于没问）

## 借口与回应

| 借口 | 现实 |
|---|---|
| "需求已经挺清楚了" | 清楚的标准是能写出"怎么算做完"。写不出来就是不清楚 |
| "多问几句对方会烦" | 问错方向的代价是整条链路返工。问对问题不烦，问空问题才烦 |
| "我大概猜到意思了" | 猜到的写进 `未验证：`，别写进结论 |
| "先做着，边做边问" | 做的过程中产生的假设会变成代码里的既成事实 |
| "这个不用问，行业惯例" | 惯例是习惯，不是约束。写出来让对方确认一次 |
| "他已经决定了，我照做就行" | 照做一个不解决问题的方案，比拒绝贵得多。先摆证据，决定权仍在他 |
| "问题攒一起一次问完" | 一次问 10 个，对方只答 3 个。分轮 |

## 红旗

- 问题列表里有任何一个搜一下就能答
- 证据指向别的原因，你却把它写成 Q3 里的一句"如果……"
- 四问齐了还在问架构问题（窗口算法、日志落点、测试框架）
- 你在替对方填空
- 四问没齐就开始写方案
- 问了但没有 `未验证` 清单
